# Declarative PMCR-O Migration

Status: active

The Microsoft Agent Framework declarative workflow is the strategic PMCR-O orchestration path. The hand-rolled `PmcroLoop`/`WorkflowBuilder` path remains available only until declarative parity is demonstrated.

Validation gates before removing the legacy path:

1. Planner receives the real seed intent.
2. MCP execution produces a normalized evidence artifact.
3. Checker receives both success criteria and evidence.
4. Every success criterion maps to at least one CheckItem/evidence item.
5. Gate cannot pass when evidence coverage is missing.
6. Reflector receives the Checker verdict and can request a bounded retry.
7. Sealed trail artifacts are equivalent to the native workflow path.
8. Filesystem, Terminal, and Playwright MCP connectivity remains proven.
9. CopilotKit remains UI/transport only; MAF remains execution runtime.
10. Runtime tests pass before the legacy orchestrator is removed.
