# Evaluation

Evaluation measures PMCR-O behavior independently from production runtime state.

Recommended suites:

- Planner trail validity
- Maker artifact correctness
- Checker precision/recall
- Reflector actionability
- Orchestrator routing correctness
- Evidence completeness
- Workflow recovery/checkpoint behavior

Training datasets may be generated from evaluation data, but training infrastructure does not belong in `.pmcro/`.
